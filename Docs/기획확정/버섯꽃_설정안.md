# 버섯꽃 (Mushbloom) 설정안

## 한 줄 컨셉
보랏빛으로 은은하게 빛나는 버섯형 꽃. **물을 주지 않아도 자라서, 손이 가장 덜 가면서 준수한 수익을 내는 작물**.

## 고유 규칙
- **물이 필요 없음.** 개간 · 심기 · 수확만 하면 됨.
- 심고 2일 뒤 수확, 한 번에 2묶음.
- 버섯형이라 **진주핵꽃의 먹이로 쓸 수 없음.**
- 거대 작물 가능 (2%, 수확량 2.5배).
- 프로토에서 첫 해금 작물: 2일차 정산 해금 → 3일차 심기 → 5일차 첫 수확.

## 수치

| 항목 | 값 |
|---|---|
| 씨앗가 | 30 |
| 성장 | 2일 |
| 물 | 불필요 |
| 판매가 | 묶음당 50 |
| 수확량 | 2묶음 |
| 일일 수익 (칸당) | 35.0 |
| 일일 입고량 | 기본 5개 → 최대 20개 (스킬 "풍성한 입고") |
| 해금 | 3 SP |
| 분류 | 데모 |

> 수치는 임시값이며 프로토 완성 후 검증 단계에서 조정. (2026-10-13 개정: 씨앗 20 → 30, 판매가 40 → 50, 물 2일 1회 → 불필요)
