# 등불 열매 (Lanternfruit) 설정안

## 한 줄 컨셉
금빛 등불 같은 열매가 맺히는 작은 나무. **첫 수확까지 오래 걸리지만, 오래 재수확할수록 이득이 커지는 장기 투자 작물**.

## 고유 규칙
- 나무형: 한 번 심으면 6일 뒤 첫 수확, 이후 **3일마다 다시 열림**. 총 5회 수확 후 시듦.
- **매일 물**을 줘야 자람 (재수확 대기 중에도).
- 첫 수확만 하고 끝내면 버섯꽃보다 손해, **끝까지 키우면 버섯꽃의 1.6배** 수익.
- 진주핵꽃의 먹이로 쓸 수 있지만 비싸서 효율은 낮음.
- 나무형이라 거대 작물 제외.
- 프로토에서 두 번째 해금 작물: 5일차 정산 해금 → 6일차 4칸 심기.

## 수치

| 항목 | 값 |
|---|---|
| 씨앗가 | 70 |
| 성장 | 6일, 이후 3일마다 재수확 |
| 물 | 매일 |
| 판매가 | 110 |
| 수확량 | 회당 2 |
| 수확 횟수 | 5회 (총 18일) |
| 일일 입고량 | 기본 4개 → 최대 12개 (스킬 "풍성한 입고") |
| 해금 | 6 SP, 선행: 버섯꽃 해금 |
| 분류 | 데모 (데모 안에서는 심기까지) |
