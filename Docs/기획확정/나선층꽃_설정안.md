# 나선층꽃 (가칭) 설정안

## 한 줄 컨셉
꽃잎 판이 이중 나선 줄기를 따라 층층이 쌓이는 외계 식물. **급전이 필요하면 바로, 더 벌고 싶으면 기다려서 수확하는 유연한 작물**.

## 고유 규칙
- 심고 **4일 뒤 수확 가능** (수확량 3).
- 다 자란 뒤에도 **물을 준 날은 밤마다 수확량 +1**, 최대 6까지 늘어남.
- 최대 6에 도달하면 더 늘지 않고 그대로 유지 (줄어들지 않음).
- 핵심 선택: **바로 거둘지, 매일 물을 주며 최대까지 키울지.**

## 수치

| 항목 | 값 |
|---|---|
| 씨앗가 | 90 |
| 성장 | 4일 (이후 하루마다 수확량 +1, 7일차 최대) |
| 물 | 매일 |
| 판매가 | 꽃잎 1묶음 90 |
| 수확량 | 3 ~ 6묶음 |
| 일일 수익 (칸당) | 45.0 (4일 수확) ~ 64.3 (7일 최대 수확) |
| 일일 입고량 | 기본 2개 → 최대 10개 (스킬 "풍성한 입고") |
| 해금 | 9 SP, 선행: 등불 열매 해금 |
| 분류 | 2차 콘텐츠 |

> 수치는 임시값이며 프로토 완성 후 검증 단계에서 조정. (2026-10-13 개정: 씨앗 60 → 90, 판매가 60 → 90)
