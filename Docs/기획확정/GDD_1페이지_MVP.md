# Nevrian Glow Farm — GDD 1페이지 (2026-10-14)

| 항목 | 내용 |
|---|---|
| 한 줄 컨셉 | 영원한 황혼의 외계 행성에서 버려진 농장과 가게를 되살려, 빛나는 작물을 기르고 어질러진 가게를 정리해 파는 **1인칭 농사 + 가게 정리 시뮬레이션** |
| 장르 · 엔진 | 농사 · 경영 · 정리 시뮬레이션 / Unity, 1인칭, PC |
| 타깃 | 스타듀밸리 · 정리형 진열 게임을 좋아하는 아늑한 게임 플레이어 |
| 플레이 시간 | 데모(MVP) 목표 경험 1~6일차 약 30~40분, 이후 계속 플레이 가능 |

## 핵심 재미 (디자인 기둥)
1. **신비로운 재배** — 스스로 빛나는 외계 작물이 밤새 자라 있는 아침.
2. **정리의 손맛** — 흩어진 상품을 종류별로 제자리에 놓고, 가게가 반짝이는 순간.
3. **눈에 보이는 성장** — 도구가 빨라지고, 손님이 입소문으로 늘고, 밭과 가게가 넓어짐.

## 하루 루프
상점(씨앗 구매) → **농사**(괭이 개간 · 심기 · 물 · 수확 · 창고) → **가게 정리**(흩어진 상품 줍기 · 흐트러진 진열 바로잡기 · 얼룩 · 쓰레기) → **진열**(과일 진열대 = 작물 한 종류 · 1층, 일반 진열대 = 가공품 · 3층 · 2차) → **자동 장사**(30초) → **정산**(매출 · 청결/정돈 등급 · 레벨업) → **스킬** → 다음 날

## 핵심 시스템 요약
| 시스템 | 요점 |
|---|---|
| 농사 | 밭 1개 = 2×2칸. 시작 8밭(32칸) → 확장 4회 최대 64밭(256칸). 괭이 3 · 물뿌리개 3 · 대걸레 3등급 |
| 인벤토리 | 핫바 4(→8) + 가방 4(→32), 도구도 칸 차지. 좌클릭 사용 · E 손 동작 · Q 내려놓기 |
| 가게 정리 | 1일차 · 매장 확장 때만 대청소. 평소엔 어제 장사의 흔적(안 팔린 상품 · 흐트러진 진열 · 발자국) 정리 |
| 손님 | 입소문 확산 모델: 1일차 1명 → 6일차 약 10명 → 기본 매장 약 20명 포화. 청결 · 정돈 · 품절이 다음 날 손님에 영향 |
| 성장 | 레벨업(매출 = 경험치)마다 SP 3. 스킬 3탭 31종, 상점 18종 (작물 해금 → 상점 입고) |
| 2차 확장 | 신규 작물(나선층꽃 · 진주핵꽃), 가공 3종 · 레시피 10, 매장 확장 5회, 펠월드식 자동화 |

## 데모 목표 경험 (1~6일차)
1일차 버려진 가게 대청소 · 첫 손님 1명 → 2일차 첫 수확(1일차 4칸) · 월광 10칸 심기 · 버섯꽃 해금 → 3일차 버섯꽃 3칸 · 4일차 4칸, 흩어진 상품 정리 시작 → 5일차 첫 버섯꽃 수확 · 등불 해금 → 6일차 등불 4칸 심기 → 이후 계속 플레이 가능

# MVP 범위 확정 (첫 사용자 테스트 = 10/25 알파 빌드, 10/28~30 최종 2차 테스트 · 2026-10-19 갱신)

원칙: **아래 "포함" 외에는 새로 넣지 않는다 (범위 동결).** 수치는 검증 단계에서 조정.

## 포함 — P0 (없으면 데모가 성립하지 않음)
| 영역 | 내용 |
|---|---|
| 하루 루프 | 단계 진행, 장소 이동(농장 ↔ 가게), 밤 처리, 저장 · 이어하기 |
| 농사 | 괭이 개간 · 심기 · 물 · E 수확, 작물 3종(월광 뿌리 · 버섯꽃 · 등불 열매), 시작 8밭 |
| 인벤토리 | 핫바 4 + 가방 4, 창고, 바닥 아이템 내려놓기 · 줍기 |
| 가게 정리 | 1일차 대청소, 흩어진 상품 · 흐트러진 진열 · 얼룩 · 소량 쓰레기, 청결도 + 정돈도 |
| 진열 | **과일 진열대 3대** (1층 낮은 판매대 · 한 대에 한 종류 · 30개, 매장 가운데), 진열 홀로그램 스냅. 일반 진열대(3층 · 가공품)는 가공과 함께 2차 |
| 장사 · 손님 | 입소문 손님 모델(1일차 1명), 자동 판매 30초, 계산대 줄 |
| 성장 | 경험치 · 레벨업 · SP, 상점(씨앗 · 도구), 스킬: 버섯꽃 · 등불 해금 |
| 정산 등급 | 정산 화면 · 가게 HUD의 청결 · 정돈 등급(S ≥ 0.95 · A ≥ 0.80 · B ≥ 0.60 · C) |
| UI | 타이틀, 농사 · 가게 HUD, 인벤토리, 창고, 상점, 정산, 스킬트리, 일시정지 |

## 포함 — P1 (일정이 되면 넣음, 빠져도 데모 성립)
| 영역 | 내용 |
|---|---|
| 도구 · 소모품 | 괭이 · 물뿌리개 · 대걸레 업그레이드, 비료, 스프링클러(밭 모서리 설치) |
| 스킬 | 데모 범위 나머지 (풍성한 입고, 물뿌리개 라이선스, 청결 유지, 간판, 단골의 장바구니, 신선 작물 프리미엄, 분주한 손, 가방 라이선스, 가벼운 발걸음, 거대한 꿈) |
| 상점 | 밭 확장권, 가방 확장, 과일 진열대 추가 구매 (진열대는 2차) |
| 정리 연출 | 외곽선 표시, "정돈 완료" · 반짝이는 가게 연출 (등급 표시는 P0) |
| 설치물 회수 | E 길게 → 회수 · 옮기기 (진열 가구 · 스프링클러) |
| 기타 | 튜토리얼 대사, 거대 작물, 장날(7일마다 — 데모 6일 안에는 미발생) |

## 제외 — 2차 (MVP 이후)
나선층꽃 · 진주핵꽃, 가공 기구 3종 · 레시피 · 가공품 진열 판매, 매장 확장, 펠월드식 자동화, 비료 분사기 · 자동 수확기 · 씨앗 추출기, 새 지역 · 장식 · 조명, 청소 v1 아이디어(숨은 얼룩 · 이끼 · 빛벌레 · 청소 반딧불이), 활동 숙련도 · 도감 · 손님 주문, 레벨 공식 · 후반 경제 개편, 장사 중 플레이어 선택 요소

## 사용자 테스트 관찰 항목 (현행 유지 결정에 따른 확인 포인트)
- 매일 다시 개간하는 일을 지루해하는가 (몇 일차부터?)
- 하나씩 진열하는 클릭이 부담인가 (장날 · 6일차 이후)
- 7일차 이후 계속 플레이 시 무엇을 목표로 삼는가, 언제 그만두는가
