# 진주핵꽃 (Pearlcore Bloom) 설정안

## 한 줄 컨셉
다른 작물의 열매를 삼켜 소화하고, 몸 중심에 마물의 핵 같은 **진주핵**을 금빛으로 키워내는 외계 식물. **손이 가장 많이 가지만 수익이 가장 높은 꽃**.

## 고유 규칙
- 다 자라면 중심에 작은 **휴면 핵**만 품고 멈춤. 먹이를 주지 않으면 수확할 것이 없음.
- **먹이 주기**: 버섯형을 제외한 작물(월광 뿌리, 등불 열매, 나선층꽃 등)을 들고 상단 입구에 E → 1개를 삼킴.
- 먹으면 **입을 닫고 소화** → 중심의 핵이 맺혀 **3일에 걸쳐 금빛으로 익음**. 소화 중에는 더 먹일 수 없음.
- 익은 핵을 조준 E로 수확 → **진주핵** 아이템. 무엇을 먹였든 진주핵은 **고정 가격**.
- 수확 후 다시 휴면으로 돌아가 반복 사용. **3회 수확하면 식물이 시들어 사라지고** 칸은 미개간으로 돌아감.
- 가장 싼 **월광 뿌리를 먹일 때 효율이 가장 높음** → 월광 뿌리가 후반까지 먹이로 쓰임.

## 수치

| 항목 | 값 |
|---|---|
| 씨앗가 | 150 |
| 성장 | 6일 (다 자란 뒤 휴면) |
| 물 | 성장 중 매일, 다 자란 뒤 불필요 |
| 먹이 | 버섯형 제외 작물 1개 / 회 |
| 소화 · 핵 성숙 | 3일 |
| 판매가 | 진주핵 1개 450 (고정) |
| 수확 횟수 | 3회 후 식물 소멸 (총 수명 15일) |
| 일일 입고량 | 기본 1개 → 최대 8개 (스킬 "풍성한 입고") |
| 해금 | 12 SP, 선행: 등불 열매 해금 |
| 분류 | 2차 콘텐츠 (가공 단계) |

### 먹이별 수익 (칸당)

| 먹인 작물 | 작물 판매가 | 1회 이익 (450 − 먹이) | 다 자란 뒤 일일 수익 | 수명 전체 일일 수익 |
|---|---|---|---|---|
| **월광 뿌리** | 18 | 432 | 144.0 | **76.4** |
| 나선층꽃 꽃잎 | 90 | 360 | 120.0 | 62.0 |
| 등불 열매 | 110 | 340 | 113.3 | 58.0 |

> 수명 전체 일일 수익 = (3회 이익 합 − 씨앗가 150) ÷ 15일 (성장 6일 + 소화 3일 × 3회).
> 수치는 임시값이며 프로토 완성 후 검증 단계에서 조정. (2026-10-13 개정: 진주핵 220 → 450, 수확 4회 → 3회)
