# 월광 뿌리 (Moonroot) 설정안

## 한 줄 컨셉
위는 보랏빛, 끝은 시안으로 빛나는 통통한 뿌리. **싸고 빠르게 자라는 기본 작물이자, 후반에는 진주핵꽃의 가장 좋은 먹이**.

## 고유 규칙
- 심은 다음 날 바로 수확 가능 (성장 1일). 매일 심고 거두는 현금 흐름 작물.
- 오프닝에서 버려진 농장에 2개가 남아 있음 (시작 작물, 창고 보관).
- 진주핵꽃에 먹이면 **가장 효율이 높은 먹이** (진주핵 1개 이익 432).
- 거대 작물 가능: 밭 4칸이 모두 다 자란 채로 밤을 맞으면 2% 확률로 합쳐짐, 수확량 2.5배.

## 수치

| 항목 | 값 |
|---|---|
| 씨앗가 | 10 |
| 성장 | 1일 |
| 물 | 매일 |
| 판매가 | 18 |
| 수확량 | 1 |
| 일일 수익 (칸당) | 8.0 |
| 일일 입고량 | 기본 10개 → 최대 40개 (스킬 "풍성한 입고") |
| 해금 | 기본 |
| 분류 | 데모 |

> 수치는 임시값이며 프로토 완성 후 검증 단계에서 조정. (2026-10-13 개정: 판매가 15 → 18)
