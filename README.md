# Nevrian Glow Farm

외계 행성의 발광 작물을 키워 직접 운영하는 가게에서 파는 3D 1인칭 농사·경영 시뮬레이션 (Unity 6000.3.25f1 · URP · PC).
Unity 프로젝트 폴더는 저장소 안의 **`Nevrian Glow/`** 이다.

## 브랜치 — 내 파트는 어디에 올리나

| 브랜치 | 누가 | 사용법 |
|---|---|---|
| `Art` | 아트 | [BRANCH_ART.md](BRANCH_ART.md) |
| `Animator` | 모션 | [BRANCH_ANIMATOR.md](BRANCH_ANIMATOR.md) |
| `Sound` | 사운드 | [BRANCH_SOUND.md](BRANCH_SOUND.md) |
| `dev` · `main` | 개발 | [BRANCHES.md](BRANCHES.md) — 전체 운영 방식 |

**한 줄 요약**: 자기 브랜치에서 → 작업 전 `dev`를 가져오고 → 자기 폴더에만 에셋을 넣고 → 커밋 · push → 납품 기록 한 줄 → 개발에게 알림.
