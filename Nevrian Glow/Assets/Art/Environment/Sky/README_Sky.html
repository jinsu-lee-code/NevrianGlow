배경 씬 Lighting 창 (Window ▸ Rendering ▸ Lighting ▸ Environment)
  • Skybox Material = M_Sky_DeepBlue
  • Environment Lighting Source = Skybox (주변광도 하늘 색에서 옴)
  • Sun Source = 배경 씬의 Directional Light
  • Unity 기본 Fog는 꺼져 있음 — 지면 안개는 GroundFog 스크립트가 셰이더로 그림 (설정과 무관)

게임에서 하늘이 적용되는 방식

  1. Core 씬 자체의 Lighting은 Unity 기본 하늘(Default-Skybox)이다 — 활성 씬이 Core라서 로딩 직후 몇 프레임은 기본 하늘.
  2. Farm · Shop · BackGroundScene이 다 올라오면 ZoneTransition(_Project/Scripts/Systems/Zones/)이 하루 시작 구역 zone_farm에 도착시키며 RenderSettings.skybox = zone_farm.skybox(= M_Sky_DeepBlue), 주변광 = Skybox로 바꾸고 DynamicGI.UpdateEnvironment().
  3. 연결 위치: _Project/Data/.../zone_farm.asset의 Skybox 칸 · Use Skybox Ambient. (PlaceholderDataSetup.cs가 이 칸에 하늘 재질을 경로로 넣음)
확인 방법: Core로 실행 → 로딩이 끝나면 하늘에 노을 구름 · 달 · 고리 행성 · 오로라가 보이면 정상. 기본 하늘색이 계속 보이면 zone_farm의 Skybox 칸이 비었는지 확인.

건드리면 안 되는 것

  • M_Sky_DeepBlue의 _PlanetSkyDraw 값은 항상 1 (행성 끄기는 스크립트가 전역 값으로 처리)
  • _Project/Scripts/Editor/PlaceholderDataSetup.cs가 M_Sky_DeepBlue.mat를 경로로 찾음 — 파일 이름 · 위치 변경 금지
